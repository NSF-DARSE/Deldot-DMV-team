# Out-of-State Tag Holder Challenge

This package contains the challenge data and materials needed to prepare and submit a solution.

## Contents

- `Challenge_Brief.md` - operational problem and required outcome
- `Data_T0/` - initial evidence files
- `Data_T1/` - later evidence files
- `Development_Labels/Development_Labels.csv` - labeled development cases
- `Data_Dictionary.csv` - field definitions
- `Data_Inventory.md` - file inventory
- `Submission_Format.md` - required prediction-file schema
- `Submission_Template.csv` - candidate/phase submission template
- `Synthetic_Data_Notice.md` - synthetic-data and location-representation notice

The package intentionally does not prescribe a solution method.
