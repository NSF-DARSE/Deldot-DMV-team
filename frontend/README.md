# Delaware DMV Review Dashboard

React/Vinext frontend for the human-in-the-loop review queue.

```bash
npm install
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000 npm run dev
npm test
```

The complete architecture, data/model pipeline, backend instructions, decision-support safeguards, and regeneration workflow are documented in the project-level `README.md`.
