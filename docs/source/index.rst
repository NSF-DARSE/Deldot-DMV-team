Case Study: Delaware DMV Out-of-State Tag Holder Review
=======================================================

Decision-support prototype for reviewing possible out-of-state tag holders.
The system produces T0 and T1 review classifications, class probabilities,
and a review-priority score. It does not determine residency or enforcement.
